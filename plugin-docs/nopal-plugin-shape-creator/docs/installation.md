# Instalación

**Configuración → Galería de plugins → Creador de formas → Instalar.** NOPAL clona el repositorio en `plugins/shape-creator/` y carga su interfaz al momento. Al no tener backend, **no hace falta reiniciar NOPAL**.

No requiere dependencias adicionales.
