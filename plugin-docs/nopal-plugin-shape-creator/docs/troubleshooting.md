# Solución de problemas

| Problema | Qué hacer |
|---|---|
| El plugin no aparece en el menú | Debe estar instalado desde la Galería. Recarga la página |
| No se puede guardar en la biblioteca | Comprueba que tu sesión siga activa (vuelve a iniciar sesión) |
| Una capa no se puede eliminar | Debe quedar **al menos una capa** |

:::caution Pendiente
El plugin no tiene pruebas automáticas propias (no tiene backend): su validación es manual en el navegador, según su README.
:::
