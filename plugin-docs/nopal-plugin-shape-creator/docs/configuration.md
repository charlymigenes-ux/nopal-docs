# Configuración

El plugin **no guarda configuración propia en el servidor**: no tiene backend ni archivos de estado.

- **Permiso declarado (informativo):** guardar archivos en la biblioteca.
- El idioma se toma del atributo `lang` del documento o de `localStorage['language']`. Incluye diccionarios por idioma y cae en inglés si no tiene el activo.
