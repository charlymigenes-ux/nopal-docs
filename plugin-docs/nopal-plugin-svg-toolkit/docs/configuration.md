# Configuración

No guarda configuración en el servidor.

- **Tolerancia** de simplificación: se elige en la propia herramienta.
- **Permiso declarado (informativo):** leer y guardar archivos SVG.
- Guardar en la biblioteca usa el endpoint `/api/upload` del core.
