# Licencia, créditos y apoyo

## Licencia

NOPAL se distribuye bajo la **GNU General Public License v3.0 (GPLv3)**. El texto completo está en el archivo `LICENSE` del repositorio. Al contribuir aceptas que tu aportación se licencie bajo la misma licencia.

## Créditos de terceros

- **Tipografías:** `font-library` incluye 20 familias con la licencia **SIL Open Font License 1.1**, con su texto junto a cada tipografía.
- **opentype.js:** `font-library` lo incluye en `frontend/vendor/`.
- **pypixelcolor:** `matriz-led` lo usa para hablar con las pantallas iPixel; se instala aparte.
- **Spoolman:** el plugin Materiales se integra con este proyecto externo.

El publicador declarado en los manifiestos de los plugins oficiales es **NOPAL Labs**.

## Seguridad

Para reportar una vulnerabilidad, usa el aviso privado de seguridad del repositorio de GitHub y **no abras un *issue* público**. Ver [Seguridad](/02-administracion/seguridad#reportar-una-vulnerabilidad).

## Apoyar NOPAL

NOPAL es gratuito y de código abierto. Según su README, las aportaciones se destinan a **hardware para pruebas de compatibilidad**: las placas y máquinas que NOPAL no puede soportar todavía porque nadie tiene una para probar.

- Apoyo económico: la página del proyecto en **Ko-fi** o una donación por **PayPal** (los enlaces están en el README del repositorio).
- **Sin gastar nada:** registra el hardware que ya tienes en la página de colaboración del proyecto.
