# Centro de ayuda y recorrido guiado

## Centro de ayuda

Dentro de NOPAL, el Centro de ayuda reúne tarjetas por tema: Inicio, Impresoras 3D, Láser/CNC, Biblioteca, Dispositivos y sensores, Red y conectividad, Automatización, Mantenimiento, Solución de problemas y Preguntas frecuentes. Usa el buscador *«Buscar ayuda…»* para filtrarlas. Las funciones aún no disponibles aparecen como *Próximamente*.

La tarjeta **Inicio** muestra la versión de NOPAL, un enlace al repositorio en GitHub y el botón **Repetir recorrido guiado**.

## Recorrido guiado

La primera vez que entras en una sección, NOPAL muestra un recorrido corto. Existe para el panel, biblioteca, editor de G-code, consola, láser, CNC, Marlin, cola y configuración, entre otras.

- Se muestra **una vez por sección** en cada navegador.
- Para volver a verlos todos: **Centro de ayuda → Inicio → Repetir recorrido guiado**.
- Para desactivarlos: **Configuración → General → Recorrido guiado**.

## Asistente guiado de impresoras

Los administradores tienen un asistente de 6 pasos para añadir impresoras: elegir marca, preparar la impresora, buscar en la red, credenciales, verificar la conexión y finalizar. Cubre Hellbot (Marlin por USB o MKS WiFi), Bambu Lab, Elegoo y FlashForge. Se abre con **Agregar impresora (asistente guiado)** desde la tarjeta Impresoras 3D del Centro de ayuda y desde las secciones de Marlin, Elegoo y FlashForge. Ver también [Conectar tu primera máquina](./conectar-primera-maquina).
