# Glosario ES / EN

Un término, una palabra (Standard §9). Los nombres de producto no se traducen.

| Español | English | Definición |
|---|---|---|
| NOPAL | NOPAL | Panel autoalojado para impresoras 3D, láser/CNC y biblioteca de archivos. Según el SDD: *Network Operating Platform for Automation & Libraries* |
| Plugin | Plugin | Extensión instalable desde la Galería, con manifiesto `nopal-plugin.json` |
| Manifiesto | Manifest | Archivo `nopal-plugin.json` en la raíz del plugin |
| Galería de plugins | Plugin gallery | Pantalla de NOPAL para instalar, habilitar y quitar plugins |
| Máquina | Machine | Impresora 3D, láser o CNC registrado en NOPAL |
| Driver | Driver | Código del core que habla el protocolo de una marca o familia de máquinas |
| Ficha de dispositivo | Device card | Tarjeta unificada con estado y controles de una máquina |
| Rol Admin / Operator | Admin / Operator role | Los dos roles de usuario de NOPAL |
| Estado de página | Page status | Etiqueta que indica si una página es `implemented`, `convention`, `experimental`, `rfc` o `deprecated` |
| RFC | RFC | Propuesta de algo que aún no existe |
| Hardware compatible | Supported hardware | Hardware probado y listado en la matriz de compatibilidad |
