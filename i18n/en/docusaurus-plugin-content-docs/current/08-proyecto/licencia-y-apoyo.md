# License, credits and support

## License

NOPAL is distributed under the **GNU General Public License v3.0 (GPLv3)**. The full text is in the repository's `LICENSE` file. By contributing you agree your contribution is licensed under the same license.

:::caution License of the plugins
The official plugin repositories that were reviewed **do not include a `LICENSE` file**. `font-library` does include the licenses of its typefaces. The author should clarify each plugin's license.
:::

## Third-party credits

- **Typefaces:** `font-library` includes 20 families under the **SIL Open Font License 1.1**, with its text next to each typeface.
- **opentype.js:** `font-library` bundles it in `frontend/vendor/`.
- **pypixelcolor:** `matriz-led` uses it to talk to iPixel displays; it is installed separately.
- **Spoolman:** the Materials plugin integrates with this external project.

The publisher declared in the official plugins' manifests is **NOPAL Labs**.

## Security

To report a vulnerability, use the private security advisory of the GitHub repository and **do not open a public issue**. See [Security](/02-administracion/seguridad#report-a-vulnerability).

## Support NOPAL

NOPAL is free and open source. According to its README, contributions go toward **hardware for compatibility testing**: the boards and machines NOPAL cannot support yet because nobody has one to test against.

- Financial support: the project's **Ko-fi** page or a **PayPal** donation (the links are in the repository README).
- **Without spending anything:** register the hardware you already own on the project's collaboration page.
