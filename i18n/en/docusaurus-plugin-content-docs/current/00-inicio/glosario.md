# ES / EN glossary

One term, one word (Standard §9). Product names are not translated.

| Spanish | English | Definition |
|---|---|---|
| NOPAL | NOPAL | Self-hosted panel for 3D printers, laser/CNC and a file library. According to the SDD: *Network Operating Platform for Automation & Libraries* |
| Plugin | Plugin | Extension installable from the Gallery, with a `nopal-plugin.json` manifest |
| Manifiesto | Manifest | The `nopal-plugin.json` file at the root of the plugin |
| Galería de plugins | Plugin gallery | NOPAL screen to install, enable and remove plugins |
| Máquina | Machine | A 3D printer, laser or CNC registered in NOPAL |
| Driver | Driver | Core code that speaks the protocol of a brand or machine family |
| Ficha de dispositivo | Device card | Unified card with the status and controls of a machine |
| Rol Admin / Operator | Admin / Operator role | The two NOPAL user roles |
| Estado de página | Page status | Label saying whether a page is `implemented`, `convention`, `experimental`, `rfc` or `deprecated` |
| RFC | RFC | A proposal for something that does not exist yet |
| Hardware compatible | Supported hardware | Hardware tested and listed in the compatibility matrix |
